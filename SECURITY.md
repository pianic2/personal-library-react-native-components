# Security Policy

## Supported versions

Texo is pre-1.0. Until 1.0.0 is released, only the latest published version receives security fixes.

| Version | Supported |
| --- | --- |
| latest published | yes |
| older pre-releases | no |

After 1.0.0 the supported lines follow the semver and deprecation policy (ADR 0011, owned by the E17 release tickets); this table is updated by those tickets.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

1. Preferred: use GitHub private vulnerability reporting. Open the **Security** tab of the repository and choose **Report a vulnerability**.
2. Alternative: email **info@theopificium.it** with the subject `SECURITY`, a description, the affected version and reproduction steps.

## Response targets

- Acknowledgement of your report: within 5 working days.
- Initial assessment (accepted, declined or needs more information): within 10 working days.
- Fix or mitigation plan for an accepted report: communicated after the assessment; coordinated disclosure after a fix is released.

These are targets for a small team, not a contractual commitment.
