# Branching and commit conventions (Texo V1)

Defined by ADR 0020 (`audit/adr/0020-ticket-execution-protocol.md`).

## Branches
- One branch per ticket, created from `texo/v1`: `texo/PLRNUI-<n>-<slug>`.
- Open the PR to `texo/v1`. Merge into `texo/v1` only with every integration check green and a passing independent review.
- `texo/v1` -> `main` is merged by the PO only. Sessions never push or merge `main`.

## Commit messages
Subject must match `^(add|fix|chore)\(PLRNUI-[0-9]+\): .+`, for example `add(PLRNUI-12): extend a11y helpers`. Merge commits generated by git (`Merge pull request`, `Merge branch`, `Merge remote-tracking branch`) are accepted so a ticket branch can take `texo/v1`.

## Local hooks
Install once per clone (no `package.json` change needed):

```sh
git config core.hooksPath .githooks
```

- `.githooks/commit-msg` runs `scripts/check-commit-msg.mjs` on the commit message.
- `.githooks/pre-push` refuses any push whose remote ref is `refs/heads/main`.

Hooks are a local aid; the CI checks of E18-09 are the enforced gate.
