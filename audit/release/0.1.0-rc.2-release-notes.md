# `@personal-library/react-native-components` 0.1.0-rc.2

## Release status

This is a pre-stable release candidate. It is not a stable promotion and does not authorize npm publication, Git tagging, or GitHub Release creation.

Install the candidate explicitly:

```sh
npm install @personal-library/react-native-components@0.1.0-rc.2
```

Do not use `latest` as the RC channel.

## Compatibility and evidence boundaries

- Expo SDK 57 remains a validation boundary, not an implicit peer dependency.
- React peer: `>=19.2.3 <20.0.0`.
- React Native peer: `>=0.86.0 <0.87.0`.
- Node: `>=22.13.0`.
- No new runtime/native dependency or intentional breaking public API change.
- Accessibility evidence is limited to renderer/static-contract checks; it is not VoiceOver, TalkBack, device, contrast, or focus-order certification.

Publication remains a separate review gate.
