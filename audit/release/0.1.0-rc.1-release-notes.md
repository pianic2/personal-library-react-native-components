# `@personal-library/react-native-components` 0.1.0-rc.1

## Release status

This is the first **release candidate** for the canonical package identity.
It is pre-stable: no component or API is classified as `stable`.

Do not install this RC through an implicit `latest` expectation. After publication,
install the exact prerelease version:

```sh
npm install @personal-library/react-native-components@0.1.0-rc.1
```

The intended npm dist-tag is `rc`.

## Runtime baseline

- Node: `>=22.13.0` for package development/release tooling.
- React peer: `>=19.2.3 <20.0.0`.
- React Native peer: `>=0.86.0 <0.87.0`.
- Certified Expo consumer baseline: Expo SDK `57.0.21`, React `19.2.3`, React Native `0.86.3`.

## Migration and breaking-change notes

### Canonical package identity

The consumer package is:

```text
@personal-library/react-native-components
```

Historical AURA / `@aura/ui` names are migration evidence only. There is no active
legacy package alias.

### Root API and deep imports

Consumers must import from the package root. Direct imports from `src/`, `dist/`,
component internals, preview shims, or repository-relative paths are unsupported.

### Token naming

Legacy public token names were removed before the first RC:

- `auraTokens` -> `defaultThemeTokens`
- `getAuraTokens(mode)` -> `createThemeTokens(mode)`
- `TokensSnapshot` -> `ThemeTokens`

No compatibility aliases are provided for those removed names.

### Theme provider/app shell

`ThemeProvider` is a pure theme context provider. Layout/scroll behavior belongs
to `ThemeAppShell`. Consumers relying on historical implicit provider layout must
migrate explicitly.

### Navigation labels

- `NavProvider`: beta
- `useNav`: beta
- `useNavigate`: experimental

### Stability policy

The package contains beta and experimental APIs. `stable` remains zero. A future
stable promotion requires its own evidence and governance gate.

## Package boundary

The publish whitelist is limited to:

- `dist/`
- `README.md`
- `LICENSE`
- npm-generated `package.json`

Repository-only material such as `src/`, `audit/`, `tests/`, `scripts/`, `docs/`,
`examples/`, and `.github/` must not be present in the npm tarball.
