# Support

## Where to ask

- **Usage questions and ideas:** open a GitHub Discussion if Discussions are enabled for the repository, otherwise open an issue using the Improvement Intake template (Investigation / question).
- **Bugs:** open an issue with a minimal reproduction (component, props, platform: iOS, Android or web, Expo SDK and React Native versions).
- **Security problems:** do not open a public issue. Follow [SECURITY.md](SECURITY.md).
- **Conduct concerns:** see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## What is supported

- The latest published version (see the supported versions table in [SECURITY.md](SECURITY.md)).
- Expo SDK 57 with React Native 0.86 for 1.0.
- Components documented in the repository documentation. Component stability levels (demo, prototype, stable) follow the repository's component stability classification (ADR 0003).

## What is not supported

- Older pre-release versions and unreleased branches.
- Versions of Expo or React Native outside the support matrix.
- Custom forks and private patches.

Support is provided on a best-effort basis by the maintainers.
